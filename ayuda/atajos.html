Atajos de teclado

En macOS usa Cmd donde dice Ctrl.

#Notas

AtajoQué hace
Ctrl + NNueva nota en el editor flotante
EscGuardar y cerrar el editor flotante
Ctrl + SGuardar
Ctrl + Shift + SGuardar como…
Ctrl + OAbrir un documento
Ctrl + FBuscar en la nota
Ctrl + Shift + FMostrar u ocultar la barra de íconos y las carpetas

#Escribir y dar formato

AtajoQué hace
Ctrl + B / I / UNegrita, cursiva, subrayado
Ctrl + KAgregar un enlace
Ctrl + Z / Ctrl + YDeshacer y rehacer
Ctrl + VPegar; cada línea queda como un párrafo
Tab en una listaAumentar la sangría
/ en un párrafo vacíoElegir el tipo de bloque (vista por bloques)
Clic derechoMenú con formato rápido

#Trabajar con líneas

AtajoQué hace
Alt + ↑ / Alt + ↓Mover la línea (o las seleccionadas) hacia arriba o abajo
Shift + Alt + ↑ / ↓Duplicar la línea arriba o abajo
Ctrl + Shift + KBorrar la línea
Ctrl + EnterAbrir una línea vacía debajo
Ctrl + Shift + EnterAbrir una línea vacía encima
Ctrl + LSeleccionar la línea

Cada uno se deshace con Ctrl + Z. Una imagen se mueve junto a su pie de figura, y el encabezado y el pie de página no se mueven.

#Enlazar notas

AtajoQué hace
[[Abrir el menú para enlazar otra nota; lo que escribes después la busca
↑ / ↓Elegir en el menú
Enter o TabEnlazar la nota elegida (o crearla, si no existe)
EscCerrar el menú y dejar el texto como está
Clic sobre un enlaceIr a la nota enlazada

#Lyrics

AtajoQué hace
EspacioReproducir o pausar
← / →Retroceder o avanzar 5 segundos
FMaximizar o restaurar la letra
HMostrar u ocultar la barra de reproducción
EscRestaurar o cerrar la vista de letra

Anotaciones: lo que va entre corchetes, como [verso], no se muestra al reproducir ni se sincroniza.
