# Take Notes

Instaladores y actualizaciones de **Take Notes**, una app de notas para escribir sin pensar en bloques: ideas, listas y letras de canciones sincronizadas en un solo texto que fluye.

## Descargar

Entra a **[Releases](https://github.com/OrionTheProgrammer/TakeNotes-releases/releases/latest)** y descarga:

- **Windows 10/11:** `TakeNotes-win-Setup.exe`. Se instala para tu usuario, sin pedir permisos de administrador, y se actualiza sola.
  - Si Windows muestra «Windows protegió su PC», pulsa **Más información › Ejecutar de todas formas**. El instalador todavía no tiene firma digital.
- **Windows sin instalar:** `TakeNotes-win-Portable.zip`. Esta versión no se actualiza sola.
- **Linux:** el `.AppImage`, cuando esté disponible.

## Actualizaciones

La app busca nuevas versiones al abrirse, las descarga en segundo plano y te avisa para reiniciar. También puedes buscarlas en **Configuración › Ayuda › Actualizaciones**.

## Apoyar

Take Notes es gratis y lo hace una sola persona. Si te sirve, puedes invitar un café en **[ko-fi.com/takenotes](https://ko-fi.com/takenotes)**.
